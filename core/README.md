# Motor de Solqubit CMS

Aplicación Laravel 13 y Filament 5. Esta carpeta es privada: la raíz pública del servidor debe apuntar a `../site`, nunca al motor completo.

Consulta [el README principal](../README.md) para preparar el entorno local, ejecutar las pruebas y generar el instalador. [docs/INSTALL.md](../docs/INSTALL.md) explica el despliegue en alojamiento.

El asistente crea al administrador y, si se elige, una sola entrada de muestra. No hay cuentas predeterminadas ni un seeder automático de usuarios.

Solqubit se distribuye con licencia MIT (ver [LICENSE](../LICENSE)). Laravel, Filament y las demás dependencias mantienen sus propias licencias, incluidas en sus paquetes.
